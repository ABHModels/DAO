# Figure 6 — Comptonized slab benchmark against `compPS`

**Author:** Yimin Huang · Fudan University · huangym23@m.fudan.edu.cn (hyimin0924@gmail.com)

DAOv2.0 (RT solver, `-test_rt compps` mode) on an isothermal, pure-scattering
slab compared against the Xspec `compPS` model (Poutanen & Svensson 1996),
one `compPS` evaluation per emergent inclination. Run `8c3e57d7`:
kT_e = 60 keV, kT_bb = 0.1 keV, vertical Thomson depth τ = 0.5. The compps
test mode uses the NA=10 double-Gauss angle grid, so the 5 outgoing μ > 0
nodes `{0.0469, 0.2308, 0.5, 0.7692, 0.9531}` coincide with compPS's internal
quadrature abscissas (angular interpolation is then exact). Two panels:
- **Left (2×2):** flux-normalised emergent spectra per inclination (shape).
- **Right:** limb-darkening law `F(μ)/F(μ_max)`, `F = μ·I` (energy-integrated).

## Files
- `emergent_compps.dat` — RT emergent intensities I(μ,E) at the 10 double-Gauss μ nodes.
- `params.json` — run parameters.
- `compps_8c3e57d7_mu*.dat` — `compPS` spectrum per outgoing μ (regenerated by the script).
- `comppsGenerator.py`, `compps_compare_8c3e57d7.{png,pdf}`.

## Requirements
**This figure needs HEASoft / PyXspec** — the script builds the `compPS` model
through Xspec. Set up HEASoft before running:
```bash
export HEADAS=/path/to/heasoft/arch && source $HEADAS/headas-init.sh
```

## Run
```bash
python comppsGenerator.py
```
No arguments needed. The script reads `emergent_compps.dat` + `params.json`,
regenerates the `compps_*.dat` files via Xspec, and writes the figure.

`compPS` restricts `cosIncl` to [0.05, 0.95], so the two extreme double-Gauss
nodes (μ = 0.0469, 0.9531) fall just outside and are clamped to 0.05 / 0.95 —
the only nodes where compPS's interpolation is not exact (flagged on stdout).
The RT intensity is multiplied by μ (`F = μ·I`) to match `compPS`, which reports
the foreshortened observed flux of a flat slab.
