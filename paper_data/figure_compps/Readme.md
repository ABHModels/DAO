# Figure 6 — Comptonised slab benchmark against `compPS`

**Author:** Yimin Huang · Fudan University · huangym23@m.fudan.edu.cn

DAO (`-test_rt compps` mode) on an isothermal, pure-scattering slab compared
against Xspec `compPS` (Poutanen & Svensson 1996). Run `8c3e57d7`:
kT_e = 60 keV, kT_bb = 0.1 keV, Thomson depth τ = 0.5. The NA=10 double-Gauss
angle grid makes the 5 outgoing μ > 0 nodes coincide with compPS's quadrature
abscissas, so the angular comparison is exact. Two panels:

- **Left (2×2):** flux-normalised emergent spectra per inclination (shape).
- **Right:** limb-darkening law `F(μ)/F(μ_max)`, `F = μ·I` (energy-integrated).

## Files
- `emergent_compps.dat` — RT emergent intensities I(μ,E) at the 10 μ nodes.
- `params.json` — run parameters.
- `compps_8c3e57d7_mu*.dat` — `compPS` spectrum per μ (regenerated by the script).
- `comppsGenerator.py`, `compps_compare_8c3e57d7.{png,pdf}`.

## Run (needs HEASoft / PyXspec)
The script builds the `compPS` model through Xspec, so source HEASoft first:
```bash
export HEADAS=/path/to/heasoft/arch && source $HEADAS/headas-init.sh
python comppsGenerator.py
```
No arguments needed; it reads `emergent_compps.dat` + `params.json`, regenerates
the `compps_*.dat` files via Xspec, and writes the figure.

**Note:** `compPS` restricts `cosIncl` to [0.05, 0.95], so the two extreme nodes
(μ = 0.0469, 0.9531) are clamped (flagged on stdout). The RT intensity is scaled
by μ (`F = μ·I`) to match compPS's foreshortened flat-slab flux.
